# PS Chas APK Builder

هذا المشروع هو نسخة محترفة ومبسطة لتطبيق صالة الألعاب PS Chas باستخدام Kotlin و Jetpack Compose.

## المتطلبات
- Android Studio Ladybug أو أحدث
- JDK 17
- Android SDK 35

## تشغيل المشروع
1. افتح المشروع في Android Studio.
2. انتظر حتى يكتمل تحميل Gradle.
3. من القائمة: Build > Build Bundle(s)/APK(s) > Build APK(s)
4. سيظهر APK في المسار التالي:
   - app/build/outputs/apk/debug/app-debug.apk

## ملاحظات مهمة
- تم تنسيق المشروع ليبنى بشكل مستقر في Android Studio.
- إذا ظهر أي خطأ في Gradle، تأكد من تحديث Android SDK وJDK 17.
- المشروع الحالي هو نسخة عملية وقابلة للتنفيذ، ويمكن تطويره لاحقاً بأكثر من شاشة ووظائف.
