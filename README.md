# PS Chas APK Builder

هذا المستودع يحتوي على مشروع Android جاهز مبني بـ Kotlin + Jetpack Compose.

## التشغيل
1. افتح المشروع في Android Studio.
2. انتظر حتى يكتمل تحميل Gradle.
3. من القائمة: Build > Build Bundle(s)/APK(s) > Build APK(s)
4. سيظهر APK في المسار التالي:
   - app/build/outputs/apk/debug/app-debug.apk

## ملاحظات
- المشروع تم تصميمه كنسخة عملية ومبسطة لتطبيق صالة الألعاب PS Chas.
- إذا أردت نسخة أكثر احترافية مع Room Database، تسجيل الدخول، وإدارة الجلسات، يمكنني تطويرها في مشروع لاحق.
